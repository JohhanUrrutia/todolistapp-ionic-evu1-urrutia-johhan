Aplicación desarrollada en Ionic con Angular, la cual nos permite administrar una lista de tareas. En la interfaz principal se muestran las tareas registradas con su título y descripción, y además es posible agregar, editar y eliminar cada una de ellas.

## Requisitos

- Node.js
- Ionic CLI

Para instalar Ionic CLI, debemos ejecutar:

```bash
npm install -g @ionic/cli
```

## Instalación

Al clonar el repositorio, debemos ingresar a la carpeta del proyecto e instalar las dependencias:

```bash
git clone https://github.com/TU_USUARIO/miApp.git
cd miApp
npm install
```

## Ejecución

Para ejecutar la aplicación en el navegador:

```bash
ionic serve
```

Con ello, la aplicación se abrirá en `http://localhost:8100`.
